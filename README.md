# Portofolio Statis (Siap GitHub Pages)

Versi ini menggunakan HTML, CSS, JavaScript, dan `data/portfolio.json` murni sehingga bisa langsung ditampilkan di **GitHub Pages** tanpa server Python maupun layanan hosting eksternal.

## Cara Mengaktifkan di GitHub Pages
1. Unggah seluruh isi folder ini (`index.html`, `about.html`, `projects.html`, `contact.html`, `data/`, `assets/`) ke repositori GitHub Anda.
2. Di GitHub, buka tab **Settings** > **Pages**.
3. Pada bagian **Build and deployment** > **Source**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
4. Tunggu beberapa saat hingga situs aktif di `https://USERNAME.github.io/NAMA_REPO/`.

## Cara Mengubah Data / Konten
Edit langsung berkas `data/portfolio.json` dan ganti gambar di `assets/images/` sesuai kebutuhan Anda.
